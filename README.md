### 🏗️ SiteManager

**Sistema para la gestión de siniestros y reparaciones de obra.**

SiteManager nació con el objetivo de **digitalizar procesos manuales y centralizar la información** relacionada con siniestros, levantamientos y reparaciones.

**Arquitectura**

`MVC` → `Arquitectura por capas` → `API REST`

**Conceptos**

• Cotizaciones y materiales
• Seguimiento de reparaciones

### 🎬 FilmVerse

**API para una plataforma de streaming.**

Backend desarrollado con **Spring Boot** para administrar un catálogo compuesto por series, temporadas y episodios.

El proyecto implementa separación de responsabilidades entre dominio, persistencia y capa web.

**Tecnologías**

`Java` `Spring Boot`
`PostgreSQL` `JPA` `MapStruct`

**Incluye**

• CRUD de entidades
• Relaciones entre entidades
• Servicios y repositorios
• Modelado relacional
• Swagger / OpenAPI
• Spring Security
• JWT
